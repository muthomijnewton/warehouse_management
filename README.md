# Warehouse Management

A Frappe Framework application for managing warehouse inventory, stock movements, stock valuation, and inventory reporting.

## Features

### Inventory Management

- Item management
- Warehouse management with hierarchical warehouse trees
- Unit of Measure (UOM) management
- Stock receipts
- Stock consumption
- Stock transfers
- Stock ledger tracking

### Stock Valuation

The application supports three inventory valuation methods:

- **Moving Average**
- **FIFO (First In, First Out)**
- **LIFO (Last In, First Out)**

Valuation is applied to:

- Stock receipts
- Stock consumption
- Stock transfers

FIFO and LIFO transactions maintain their respective stock layers so that subsequent stock consumption uses the appropriate valuation order.

## Stock Entry

The Stock Entry DocType records inventory movements between warehouses.

Supported transaction purposes:

- **Receipt** - Adds stock to a warehouse.
- **Consume** - Removes stock from a warehouse.
- **Transfer** - Moves stock from one warehouse to another.

Each Stock Entry contains one or more Stock Entry Items.

## Stock Ledger Entry

Stock Ledger Entry records the individual inventory movements generated by Stock Entries.

Each ledger entry stores information such as:

- Posting date and time
- Item
- Warehouse
- Stock Entry reference
- Actual quantity
- Valuation rate
- Stock value
- Quantity after transaction
- Stock value after transaction

The Stock Ledger provides the transaction-level history used to determine inventory balances and valuation.

## Reports

The application provides two standard inventory reports:

### Stock Ledger

Displays the chronological history of stock movements, including quantities, valuation rates, and stock values.

### Stock Balance

Displays the current stock quantity and value for items across warehouses.

## Unit of Measure

The UOM DocType manages the units used when defining and recording inventory quantities.


## Installation

### Requirements

Before installing the application, make sure you have a working Frappe Framework development environment.

The application is currently developed and tested with:

- Python 3.10+
- Frappe Framework v15
- MariaDB
- Redis
- Node.js
- Yarn
- Frappe Bench

### Getting the Application

Clone the repository into your Frappe Bench `apps` directory:

```bash
git clone https://github.com/muthomijnewton/warehouse_management.git
```

Navigate to your Frappe Bench directory:

```bash
cd ~/frappe-bench
```

Install the application on your site:

```bash
bench --site warehouse.localhost install-app warehouse_management
```

Run database migrations:

```bash
bench --site warehouse.localhost migrate
```

Build the application assets:

```bash
bench build --app warehouse_management
```

Start the development server:

```bash
bench start
```

The application can then be accessed through the configured Frappe site.


## Usage

The typical workflow for managing inventory is:

1. **Create a UOM**
   - Define the unit used to measure an item, such as Pieces, Kilograms, or Litres.

2. **Create an Item**
   - Enter the item code, name, description, UOM, and standard cost.

3. **Create Warehouses**
   - Create the required warehouses and organize them into a hierarchical structure where necessary.

4. **Create a Stock Entry**
   - Select the transaction purpose: Receipt, Consume, or Transfer.
   - Add the relevant items and quantities.
   - Select the appropriate valuation method.

5. **Submit the Stock Entry**
   - The system validates the transaction and creates the corresponding Stock Ledger Entries.
   - Inventory quantities and stock values are updated automatically.

6. **Review Inventory Reports**
   - Use the Stock Ledger report to review individual stock movements.
   - Use the Stock Balance report to review current inventory quantities and values.

### Example Workflow

A simple inventory workflow might look like this:

```text
Create UOM
    ↓
Create Item
    ↓
Create Warehouse
    ↓
Receive Stock
    ↓
Stock Ledger Entry Created
    ↓
Consume or Transfer Stock
    ↓
Inventory Balance Updated
    ↓
Review Stock Ledger / Stock Balance
```

### Valuation Methods

When creating a Stock Entry, the valuation method determines how inventory value is calculated.

- **Moving Average** calculates the average cost of inventory after stock receipts.
- **FIFO** consumes inventory from the oldest available stock layer first.
- **LIFO** consumes inventory from the newest available stock layer first.

FIFO and LIFO maintain stock layers so that the correct valuation rate is applied when inventory is consumed or transferred.
